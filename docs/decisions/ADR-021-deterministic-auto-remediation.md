# ADR-021 — Deterministic Auto-Remediation of Semantic Drift (advisory)

**Статус:** Принято 2026-06-14
**Reviewer:** live-сессия sign-off (human-in-the-loop), ветка `feat/main-agent-token-estimate`
**Связано:** ADR-018 (semantic-плоскость audit-as-code), roadmap §XII.1, CLAUDE.md §18 (advisory vs machine-enforced). Первый класс «авто-коррекции» — опора для будущего #9 (self-governed runtime).

## Контекст

22-чек audit-suite (ADR-018) детектирует семантический дрейф, но все детекторы **detect-only** — валят, не чинят. §XII.1 рекомендует авто-ремедиацию детерминированных классов. `audit-suite:fix` (npm) уже прокидывает `--fix` в дочерние аудиторы через `process.argv.slice(2)`, но ни один аудитор флаг не реализовывал — no-op.

При детализации выяснилось (сверка с кодом), что не каждый «детерминированный» класс восстановим:
- `section-anchors` детектирует висячую `(§N)` без заголовка — **нет цели восстановления** (нельзя синтезировать заголовок; при сдвиге нумерации цель неоднозначна).
- `dead-refs` детектирует ссылку на несуществующий файл — цель **требует выбора** (несколько кандидатов).
- `path-canonical` детектирует запрещённый префикс пути — **строго детерминированный** и обратимый rewrite к относительной форме.

## Решение

1. **Граница «детерминированный».** Авто-фиксим ТОЛЬКО обратимый prefix→relative rewrite в `path-canonical`:
   - `W:/Claude/<repo>/…` → относительный путь (strip абсолютного repo-префикса);
   - `CCIP/(docs|apps|packages|.claude|infra|tools)/…` → strip `CCIP/`-префикса.
   Порядок строгий: абсолютный repo-префикс снимается первым (иначе вложенный `CCIP/` исказил бы путь).

2. **Не чиним недетерминированное.** Абсолютные `C:\Users\…` / `/home/…` не имеют детерминированной relative-цели → остаются detect-only (репортятся, не правятся). `section-anchors` / `dead-refs` авто-фикс **не получают** — не входят в детерминированный класс.

3. **Advisory, не blocking.** `--fix` запускается вручную / в CI (`npm run audit-suite:fix`), НЕ в pre-commit. Default-режим (без флага) байт-в-байт прежний detect-only blocking — авто-модификация файлов в pre-commit без ревью исключена (риск тихой неверной правки + конфликт с другими hook-writer'ами).

## Последствия

- Первый машинно-исполнимый класс авто-коррекции дрейфа — прецедент для #9.
- CLAUDE.md §18 класс «advisory»: `--fix` — конвенция запуска, не machine-enforced gate.
- §XII.1 промоутнут реализованным; capability-assessment «авто-ремедиация дрейфа» [Experimental]→частично реализован с доказательством (тест обоих режимов).
- Расширение на новые детерминированные классы — отдельным инкрементом под этим же ADR (граница «детерминированный» — критерий включения).
