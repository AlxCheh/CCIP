### C-006 — closed (переквалификация)

**Изначальная формулировка:** "security-reviewer vs ccip-security ambiguity".

**Уточнение:** это не ambiguity, а два разных агента с разделёнными ролями:

| Агент | Роль | Tools | Когда вызывается |
|-------|------|-------|------------------|
| `ccip-security` | Security Engineer (full-write) | Read, Write, Edit, Glob, Grep, Bash | RBAC-аудит, threat model, OWASP, pre-launch review, secret management |
| `security-reviewer` | Блокирующий co-agent (read-only) | Read, Glob, Grep | Параллельный review при изменениях JWT/RBAC/RLS/multi-tenancy/AuditLog с severity-вердиктом |

**Что нужно зафиксировать:** правила выбора в CLAUDE.md (сейчас `SECURITY → security-reviewer` без упоминания `ccip-security`).

**Owner:** ccip-architect (часть T2).

```json
{
  "session_id": "",
  "task": "",
  "intents": [],

```

**Последствие:** security-reviewer на шаге 1 алгоритма читает `agent_outputs[<primary_agent>].artifacts` — на пустом файле список изменённых файлов получить невозможно.
